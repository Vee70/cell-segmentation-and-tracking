# Cell Segmentation and Tracking

Segments and tracks cells in time-lapse microscopy video. Each cell gets a unique ID, colour, and trajectory. Dividing cells are marked in red and daughter cells receive new IDs. Per-frame statistics include cell count, dividing cells, and average cell size.


## Requirements
```
matplotlib=3.3.4
numpy=1.20.1
opencv=4.0.1
scikit-image=0.18.1
scipy=1.6.2
```
